# Template Projects

Welcome to the **Template Projects** repository! This collection provides a variety of project templates designed to help developers kickstart their software development projects with a well-structured and modular approach.

## Features
- **Clean Architecture Templates**: Ready-to-use templates for .NET 7 and .NET 8 projects, promoting separation of concerns and maintainability.
- **Modular Monolith Templates**: Build scalable applications with modular designs that facilitate easier testing and deployment.
- **Pre-configured Projects**: Accelerate your development process with templates that come with essential configurations out of the box.

## Technology Stack
This repository utilizes the following technologies:
- **Programming Languages**: C#
- **Frameworks**: .NET 7, .NET 8
- **Frontend**: HTML
- **Database**: T-SQL
- **Scripting**: Shell, PowerShell
- **Containerization**: Docker

## Getting Started
To get started with the templates in this repository, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MostafaHassan101/Template-Projects.git
   ```
   
2. **Navigate to the desired template folder**:
   ```bash
   cd Template-Projects/[template-folder-name]
   ```

3. **Open the project in your preferred IDE** (e.g., Visual Studio, Visual Studio Code).

4. **Restore dependencies**:
   ```bash
   dotnet restore
   ```

5. **Run the project**:
   ```bash
   dotnet run
   ```
